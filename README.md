# Memory in Light

**Memory in Light** is an interactive, research-informed web project exploring how visual ambiguity, color, light, and atmosphere can encourage personal interpretation and autobiographical association.

The project was created for a Visual Literacy research course and is based on research into visual indeterminacy, autobiographical memory, color perception, and viewing context.

## Project Question

The project asks:

**How does visual ambiguity in abstract, color-based imagery encourage autobiographical memory and personal meaning-making?**

Rather than showing viewers a specific memory or telling them what they should feel, the experience presents a series of abstract visual environments that remain intentionally unresolved.

The goal is to create enough visual structure for something to feel familiar without fully explaining what the viewer is looking at.

## The Experience

Visitors move through four full-screen visual environments that use different combinations of:

- color
- light
- darkness
- blur
- spatial suggestion
- contrast
- slow movement

The environments are intentionally not labeled with specific meanings.

For example, a viewer might interpret a glow as a window, television, hallway, sunset, reflection, distant light, or something completely different. These different interpretations are part of the project.

After viewing all four environments, participants are invited to complete a short anonymous reflection about what they noticed, what felt familiar, and which visual elements affected their interpretation.

Only after submitting the reflection is the research purpose of the project revealed.

## Design Approach

A major concept behind the project is **structured ambiguity**.

The environments are designed to sit between two extremes:

**Too recognizable**  
The viewer immediately knows exactly what is being shown.

**Too abstract**  
There is not enough visual information for the viewer to meaningfully interpret.

**Structured ambiguity**  
The image provides enough perceptual information to suggest a space, light source, object, or atmosphere without fully resolving into one identifiable scene.

This allows the viewer's own experiences, memories, expectations, and learned associations to become part of the interpretation.

## Research-Informed Design

The project draws from research on:

- visual indeterminacy
- abstract art and individual interpretation
- autobiographical memory
- spontaneous memory retrieval
- color and emotional association
- learned and personal color associations
- viewing context
- digital versus physical art experiences

The project does **not** assume that a specific color automatically creates a specific emotion or memory.

Instead, color is treated as one part of a larger perceptual system involving hue, saturation, brightness, contrast, movement, context, and personal experience.

The project is also influenced by artists such as **James Turrell** and **Anish Kapoor**, whose work uses light, color, space, and perceptual uncertainty as part of the experience itself.

## Viewer Feedback

The current version functions as both an interactive artwork and a small design experiment.

Participants are asked questions such as:

- Did anything feel familiar?
- What did you think you were looking at?
- Did you associate any environment with a place, object, event, memory, or feeling?
- Which visual element affected your interpretation the most?
- Which environment gave you the most room to form your own interpretation?

Responses are collected anonymously through Formspree and are used to help evaluate how different visual environments are interpreted.

Participants are asked not to include identifying information.

## Accessibility

The prototype includes:

- semantic HTML
- keyboard-accessible navigation
- visible focus states
- reduced-motion support
- no rapid flashing
- responsive layouts
- screen-reader descriptions that avoid prescribing a specific interpretation

## Project Status

This project is currently in an experimental and user-testing stage.

The initial prototype explores four different visual environments. Viewer responses will help guide future revisions, including how much visual structure, color variation, movement, and spatial ambiguity should be used in the final experience.

The larger goal of the project is not to design a specific memory for the viewer, but to **design conditions in which personal meaning has room to emerge**.
